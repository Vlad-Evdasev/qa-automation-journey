# Конспект по Git

## Три зоны

- Рабочая папка → git add → staging → git commit → репозиторий

## Основные команды

- git init — создать репозиторий
- git status — посмотреть состояние
- git add . — положить всё в staging
- git commit -m "..." — сохранить снимок
- git push — отправить на GitHub

## Ветки

- git switch -c имя — создать ветку
- git merge имя — влить ветку

## Работа в команде

- Каждая задача делается в отдельной ветке
- git push -u origin имя-ветки — отправить ветку на GitHub
- Pull Request — запрос влить ветку в main, место для код-ревью
- fast-forward merge — когда main не менялся, указатель просто перематывается вперёд
