## 🧭 Как учиться

1. Открой [LEARNING_PLAN.md](LEARNING_PLAN.md), найди текущий модуль (он отмечен в [PROGRESS.md](PROGRESS.md)).
2. Изучи теорию → сделай **всю практику** → выполни **мини-проект** → закрой критерий готовности.
3. Напиши мне — я проверю, отвечу на вопросы, дам доп. задачи и отмечу прогресс.
4. Переходи к следующему модулю только после закрытого мини-проекта.

## 🤖 Как работать со мной (Claude)

Я твой ментор и помню твой прогресс между сессиями. Просто пиши по-человечески:

- **«Давай продолжим»** — я посмотрю [PROGRESS.md](PROGRESS.md) и подхвачу с нужного места.
- **«Я закончил модуль N»** — проверю, задам пару вопросов и отмечу как ✅.
- **«Объясни промисы ещё раз»** / **«Не понял тему X»** — разберу подробнее с примерами.
- **«Дай ещё практики по X»** — накину дополнительных задач.
- **«Проверь мой код»** — скинь путь к файлу, я сделаю ревью.
- **«Устрой мне мини-собеседование по фазе N»** — погоняю вопросами.
